Markdown versions of documentation pages are available by appending `.md` to page URLs; this page is available as [Markdown](https://mariadb.com/docs/server/reference/sql-functions/aggregate-functions/bit_xor.md). # BIT\_XOR ## Syntax ```bnf BIT_XOR(expr) [over_clause] ``` ## Description Returns the bitwise XOR of all bits in `expr`. The calculation is performed with 64-bit ([BIGINT](/docs/server/reference/data-types/numeric-data-types/bigint.md)) precision. It is an [aggregate function](/docs/server/reference/sql-functions/aggregate-functions.md), and so can be used with the [GROUP BY](/docs/server/reference/sql-statements/data-manipulation/selecting-data/group-by.md) clause. If no rows match, `BIT_XOR` will return a value with all bits set to `0`. NULL values have no effect on the result unless all results are NULL, which is treated as no match. `BIT_XOR` can be used as a [window function](/docs/server/reference/sql-functions/special-functions/window-functions.md) with the addition of the *over\_clause*. ## Examples ```sql CREATE TABLE vals (x INT); INSERT INTO vals VALUES(111),(110),(100); SELECT BIT_AND(x), BIT_OR(x), BIT_XOR(x) FROM vals; +------------+-----------+------------+ | BIT_AND(x) | BIT_OR(x) | BIT_XOR(x) | +------------+-----------+------------+ | 100 | 111 | 101 | +------------+-----------+------------+ ``` As an [aggregate function](/docs/server/reference/sql-functions/aggregate-functions.md): ```sql CREATE TABLE vals2 (category VARCHAR(1), x INT); INSERT INTO vals2 VALUES ('a',111),('a',110),('a',100), ('b','000'),('b',001),('b',011); SELECT category, BIT_AND(x), BIT_OR(x), BIT_XOR(x) FROM vals GROUP BY category; +----------+------------+-----------+------------+ | category | BIT_AND(x) | BIT_OR(x) | BIT_XOR(x) | +----------+------------+-----------+------------+ | a | 100 | 111 | 101 | | b | 0 | 11 | 10 | +----------+------------+-----------+------------+ ``` No match: ```sql SELECT BIT_XOR(NULL); +---------------+ | BIT_XOR(NULL) | +---------------+ | 0 | +---------------+ ``` ## See Also * [BIT\_AND](/docs/server/reference/sql-functions/aggregate-functions/bit_and.md) * [BIT\_OR](/docs/server/reference/sql-functions/aggregate-functions/bit_or.md) *This page is licensed: GPLv2, originally from* [*fill\_help\_tables.sql*](https://github.com/MariaDB/server/blob/main/scripts/fill_help_tables.sql) {% @marketo/form formId="4316" %}
